Pasta reconstruída a partir dos 12 arquivos enviados pela estudante.
Os arquivos fornecidos foram copiados sem alterar seu conteúdo.

COMO ABRIR NO VS CODE
1. Extraia o ZIP para uma pasta fácil de encontrar.
2. Abra o VS Code.
3. Clique em Arquivo > Abrir Pasta...
4. Selecione a pasta "Infancia_Viva_TCC_reconstruido".
5. Confira os arquivos na barra lateral esquerda.

ATENÇÃO AOS CAMINHOS
- index.html e as páginas referenciam "estilo.css" e "script.js".
- O menu e os formulários referenciam páginas HTML que não estão neste pacote.
- O banner espera imagens em "imagens/foto1.jpg" até "imagens/foto8.jpg".
- Os arquivos PHP dependem de "funcoes.php", que por sua vez inclui "conexao.php".
- Não é possível garantir que o site funcione por completo até recuperar/verificar
  os arquivos faltantes e o banco de dados.
